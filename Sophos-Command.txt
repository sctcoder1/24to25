NEW SOPHOS LIVE RESPONSE COMMAND
================================

Prerequisite:
The Windows 11 25H2 ISO must already be in:
C:\Win11-25H2-Upgrade

Upload this NEW file to the root of the main branch of sctcoder1/24to25:
Upgrade-23H2-to-25H2-LocalISO-Sophos.ps1

Do not replace any existing PS1.

Command:
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -Command "$u='https://raw.githubusercontent.com/sctcoder1/24to25/main/Upgrade-23H2-to-25H2-LocalISO-Sophos.ps1'; $p=Join-Path $env:TEMP 'Upgrade-23H2-to-25H2-LocalISO-Sophos.ps1'; Invoke-WebRequest -UseBasicParsing -Uri $u -OutFile $p; $expected='412EB8DDB75EE47F004C824144D516FEED2F3081FAC679B10AE750AA94A5AEA0'; $actual=(Get-FileHash -LiteralPath $p -Algorithm SHA256).Hash; if ($actual -ne $expected) { Remove-Item -LiteralPath $p -Force -ErrorAction SilentlyContinue; throw ('SHA256 mismatch. Expected ' + $expected + ' got ' + $actual) }; & $p -Install; exit $LASTEXITCODE"
